## 🚀 Featured Personal Projects

### 01. Retail Sales Analytics

**Microsoft Fabric | End-to-End Data Engineering**

<a href="https://github.com/abhilashyada/Retail-Sales-Analytics-Microsoft-Fabric-End-to-End-Data-Engineering">
  <img src="https://abhilashyada.vercel.app/projects/retail-sales-analytics/cover.webp" alt="Retail Sales Analytics - Microsoft Fabric End-to-End Data Engineering" width="100%"/>
</a>

An end-to-end data engineering and analytics solution built using Microsoft Fabric, demonstrating automated ingestion, incremental processing, data quality validation and analytics-ready data delivery.

#### Key Features

- Medallion Architecture: Bronze, Silver and Gold layers.
- Incremental ingestion using SHA-256 file fingerprinting.
- PySpark-based data transformations.
- Delta MERGE for incremental processing.
- Data deduplication, quarantine and validation.
- Soft deletion and record reactivation.
- Automated daily pipeline orchestration.
- Direct Lake semantic model and Power BI analytics.

**Technology Stack**

Microsoft Fabric · Python · PySpark · SQL · Delta Lake · OneLake · Lakehouse · Power BI
